# 设定界面app（机器人基础设置）

送药机器人系统的**子女端「机器人基础设置」界面**。机器人负责「找到人 → 送到手边 → 确认吃下」，
这一端负责**让它知道该送什么、什么时候送、能看什么**：把用药方案与隐私开关下发到机器人，
机器人据此生成**本地排程**并出药。

- 形态：**单文件静态网页**，双击 `index.html` 即开，无需服务器、无需联网、无外部依赖（字体全部回退系统字体）。
- 视觉：莱茵生命（Rhine Lab）风格 —— 深色实验室底 + 青色数据主色 + 琥珀警示 + 切角面板 / 等宽字 / 扫描线，
  与 `family-app/`（子女端提示 App）保持同一套视觉语言。
- 端口：以 414 × 872 的手机壳呈现；窄屏自动全宽。
- 版本：v1.0 / 演示用 ｜ 数据日期：2026-10-04

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `index.html` | 全部内容（HTML + CSS + JS 内联），唯一交付文件 |

## 结构：1 个设置首页 + 5 组设置 + 底部保存条

| 设置组 | 内容 |
| --- | --- |
| **用药计划** | 录入项与《机器人行为设定》§四 完全对齐：**名称 / 剂量 / 频次 / 有效期 / 与进餐关系**。频次拆成「每日 N 次 + 具体时段」，时段行可增删，每行独立设进餐关系（餐前 30 min / 餐中 / 餐后 30 min / 睡前 / 空腹 / 不限）。另提供「粘贴医嘱快速录入」，把一行医嘱（如 `碳酸钙D3片 1片 每天2次 早晚餐后 2027-01`）解析成结构化字段（草稿级，仍需进编辑核对） |
| **余量与有效期提醒** | ① **药量不足 1 天 → 提前 24 小时提醒**，卡片直接给出计算式；② **过期药品 → 提醒更换**（60 天内到期降级为提示级）；可「标记已补药 / 标记已更换 / 调整用量」，处理后时间 + 原因留痕，并附「子女端实际收到的推送」预览 |
| **装药核对** | 逐格引导核对（防错）：核对通过前该格不出药；余量为 0 标「需补药」；含废弃药片仓容量检测与清理留痕 |
| **隐私设置** | **是否启用摄像头**（关闭时明确写出代价：无法确认是否服下，只能记「已送达 / 未取走」）；**是否需要每一次用药都播报**；播报是否含剂量与进餐关系；私密区域改用门外语音。不可关闭项单列：画面不上云、私域不启用摄像头、只拍手部区域 |
| **提醒与对话参数** | 提醒间隔 2 min、未取走超时 10 min（收回药片直接报废 + 上报子女端）、白天 / 夜间音量、三级唤醒次数与间隔 |

底部**保存条**：有未下发的改动时高亮为琥珀色；「下发到机器人」写入变更日志，「放弃修改」回到已同步状态。

所有余量天数、有效期状态、每日服药次数、今日排程预览均由**页面内数据实时推导** ——
改剂量或频次后，排程与提醒立即重算。

## 与既有设定的对齐

阈值与规则取自项目文档《机器人行为设定》：

| 参数 | 值 |
| --- | --- |
| 录入项 | 药品名称 / 剂量 / 频次 / 有效期 / 与进餐关系（§四 添药设定） |
| 录入端 | 子女端 App |
| 装药核对 | App 引导逐格核对（防错） |
| 余量预警 | 药量不足 1 天 → 提前 24 小时提醒 |
| 有效期管理 | 过期药品 → 提醒更换 |
| 提醒间隔 / 未取走超时 | 2 min / 10 min（收回药片与水，药片直接报废） |
| 出药规则 | 一次一格，只出该次所需 |
| 隐私边界 | 私密区域不进入、不录像；摄像头画面不上传云端，仅本地用于「药片消失 + 杯子放回」判定 |

隐私与安全声明：**只下发结构化排程与开关，不含影像**；机器人不是医疗器械，不提供诊断、不建议加药或停药。
