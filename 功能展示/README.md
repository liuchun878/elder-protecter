## 一、整机爆炸：每个部件的功能

| 部件 | 功能 | 依据 |
| --- | --- | --- |
| **显示模块**（头部，约 7 in 屏） | **给予提示** | 屏上显示提示语 + 表情；机器人另有语音提示 |
| 头部总成 | 人机交互界面 | 显示、语音问答、状态；顶部为可拆分离面 |
| 壳体上舱段 | 包裹内部机构 | 整壳封闭，容纳电控 / 水箱 |
| **蛋壳状外壳** | **避免磕碰伤人** | 全曲面过渡、无棱角着力点，接触人体处为圆弧缓冲面 |
| **舱门（可开合）** | **打开后取出药 & 水** | 下部铰链，外开约 75°，不夹手、不挡视线 |
| 药片（该次剂量） | **送出药** | 一次一格，内部机构推送至托盘送餐区 |
| 水杯 | 送出水 | 满 60% 自动停止 |
| 升降托盘 | 送到「手一放就够到」 | 按手臂高度自动升降（行程 520 → 760 mm） |
| **移动轮组 / 底盘** | **自由行动** | 四轮独立，自主导航 / 绕障 / 回充电桩 |

## 二、右栏：表情与功能区分

| 状态 | 屏显 | 颜色 | 功能 |
| --- | --- | --- | --- |
| **STATE 01 用药时段 · 提示** | 圆眼 + 抿嘴，「请取药 · 药已备好」 | 青 `#8FDCF8` | **给予提示**：让老人知道该做什么，语气中性、指示明确 |
| **STATE 02 服药完成后 · 完成** | `^ ^` 笑眼 + 微笑弧，「已服药 · 祝您健康」 | 绿 `#7CF0A6` | **正向反馈 + 情绪安抚**：把「已完成」做得看得见，减少重复取药焦虑 |
| STATE 03 待重试 · 未完成 | 表情转琥珀色（扩展态） | 琥珀 `#D8A12A` | **温和升级**：2 min 复述一次；10 min 未取走 → 收回药片与水并上报子女端 |

设计约束：笑脸与祝福语属**非医疗表述**，不做任何疗效或诊断暗示；STATE 02 约 10 s 后回到待机。

## 三、右下：内部舱位剖面（SECTION A-A）

舱门打开后的取药闭环：开门（停稳 2 s 后）→ 老人取药 & 水 → 药片消失 + 杯子放回
→ 托盘收回，记录「日期 / 时间 / 已服药」并同步子女端；10 min 未取走则收回药片与水（药片直接报废）。

## 四、与既有设定的对齐

数值取自《机器人行为设定》：停稳 2 s 开隔离板、水杯满 60% 停止、取药判定仅靠摄像头、
餐板按手臂高度自动升降、提醒间隔 2 min、未取走超时 10 min、过门石 15 mm。
