## v2 相对 v1 的改动摘要

- **修正 13 处实质错误**，逐条记录在报告第 12 章「核验与修订记录」，**保留原错误说明、不做静默覆盖**。
  其中影响最大的三处：
  1. **3100 Hz 报警的未唤醒率 43% → 56%**（43% 是儿童与深睡青年组的数字，被误用到了听损成人组）
  2. **REMIND 试验的第三项干预「短信提醒」并不存在**（实为带拨片药瓶贴条）
  3. **听力损失与痴呆风险：期刊、年份、数值三处均误**（JAMA 2012 / 2-3-5× → Arch Neurol 2011 / 1.89-3.00-4.94）
- **驳回 3 条子代理误报**（Cochrane 引文、JAMA 作者、选择性引用三项指控均不成立）。
- **补入 15 项以上新的一手来源**，并**推翻了两条 v1 的缺口声明**（中文语音证据、互联网+护理执行数据）。
- **给出 1 处此前未披露的矛盾**（「提醒到底有没有效」：Cochrane/REMIND vs Australas J Ageing 2026），**未抹平**。

## 仍未解决的缺口（报告中已明确标注，请勿填数）

1. **没有做任何真实用户访谈**——本报告最大的方法论短板。
2. **中国本土定价区间**：京东/天猫智能药盒价格由 JS 渲染，三个子代理与主代理均未取到；只有「实体店 3900 元 vs 普通药盒几十元」两个锚点。
3. **官方语速阈值**：GB/T 45122-2024 与工信部规范 PDF 为字体内嵌编码，无法解出文本。
4. **Lancet 2024 委员会正文**：官网 403，现引用的是官方新闻稿。
5. **「误报 → 信任崩塌」在老年服药提醒语境下无任何直接实证**。
6. **中西方阻力权重的量化对比研究不存在**。
