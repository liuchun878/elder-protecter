## 2 · 回滚手册（都在本地，随时可退）

| 引用 | 指向 | 用途 |
|---|---|---|
| `backup/origin-main` | `1a6113e` | **合并前的远端 main**（最关键的退路） |
| `backup/main-老线` | `4211309` | 合并前本地 main 的那条老线（medbot-sim，5 个提交） |
| `backup/feat-s-click-seat` | `7329fe9` | 合并前我们分支的尖端 |
| tag `backup-7329fe9` | `7329fe9` | 同上（tag 形式，更难点错） |

```bash
# ① 整条 main 退回合入前的远端状态（本地）
git checkout main && git reset --hard backup/origin-main

# ② 只想撤销某一次合并（保留后续）
git checkout main && git revert -m 1 <合并提交>     # 如 1e1d9d6 / e29ef77 / c22fe4e

# ③ 我们那条分支的尖端（合并前）
git checkout feat/s-click-seat            # = 7329fe9，未被本次合并改动
```

> ⚠️ 推送前这些回滚都是**纯本地**操作；一旦推上去，回滚远端需要再推一次（仍是快进，不需要 force：
> `origin/main` 的 `1a6113e` 是本地 main 的祖先）。
