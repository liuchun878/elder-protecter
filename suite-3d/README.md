# 套房 · 3D 场景

参考 `D:\桌面\zym\zwu\WAS\电脑效果图\套房\套房.skp`（SketchUp 2022，90 MB）的空间关系，
用 Three.js 重建的可交互三维场景。**不是**把 skp 网格导出来，而是按模型里的平面布局、
家具位置与材质倾向重新建模 —— 因此每一处都能改，且体积只有 4 MB 左右。

```
suite-3d/
├─ index.html              场景本体（双击即可打开，无需服务器）
├─ vendor/three.min.js     three.js r160（本地内置，不联网也能跑）
└─ preview/                渲染样张（01~06 为本场景，00 为 skp 原始平面）
```

## 怎么打开

直接双击 `index.html`（Edge / Chrome 均可，`file://` 协议就能跑，不需要起服务器）。

## 操作

| 操作 | 作用 |
|---|---|
| 左键拖拽 | 环绕旋转 |
| 滚轮 | 缩放 |
| 右键拖拽 / Shift+左键 | 平移 |
| 双击画面 | 进入漫游；`W A S D` 前后左右、`Q E` 升降、`Esc` 退出 |
| 左侧面板 | 九个取景预设、房间标注 / 家具 / 网格开关、自动旋转、剖切高度、日光 / 黄昏 / 夜晚 |

「剖切高度」滑到 1.1 m 左右会得到一张**家具布置轴测图**（见 `preview/03-剖切.png`），
适合出图或放进汇报。

## 场景还原了什么

依据 `套房.skp` 的平面视图与轴测视图逐间还原：

```
北侧  卧室A(西北) │ 卫A(淋浴) │ 卫B(浴缸) │ 卧室B(东北)
中部  卫生间(西) │ 西走廊 │ 餐区 · 起居（东侧大空间）
南侧  卧室C(西南) │ 书房(中) │ 起居延伸（电视墙 + 南向大窗）
```

- 结构：外轮廓 13.4 × 10.6 m，层高 2.85 m；外墙 240 mm、内墙 150 mm；
  无屋顶（保留 skp 的"剖切模型"观感），门窗洞口按墙段参数开洞。
- 家具：三张 1.8 m 双人床（床头分别靠西/东/西墙，与原模型一致）、床头柜、衣柜、
  L 形起居的沙发组 + 茶几 + 电视墙 + 餐区四椅餐桌、书房书桌 + 书架、
  卫浴洁具（坐便 / 台盆 / 淋浴房 / 浴缸）、窗帘、盆栽。
- 材质：木地板、灰泥墙、石材地毯、深色石材卫浴地面全部由 canvas **程序化生成**
  （`woodCanvas / stoneCanvas / slateCanvas / linenCanvas / plasterCanvas`），
  因此没有一张外部贴图，也就没有丢失贴图的问题。

## 想改的话，改哪儿

`index.html` 里的结构很直白，按注释找即可：

| 想改什么 | 位置 |
|---|---|
| 房间划分（平面尺寸） | 顶部 `ROOMS` 对象，坐标为米、原点在西北角 |
| 墙体与门窗洞口 | 中段 `wall(x1,z1,x2,z2,厚度, [洞口])` 一串调用；`WIN/DOOR/OPEN` 生成洞口 |
| 家具布置 | `/* 布置家具 */` 段落，如 `bed(1.55, 2.05, 0)`＝平面 (1.55, 2.05) 处床头朝西 |
| 配色与质感 | `M` 材质库；颜色 / 粗糙度 / 反射强度都在这里 |
| 取景预设 | `VIEWS`；环绕视角用 `r/th/ph`，室内人眼视角用 `eye` 与 `fov` |
| 光照与时间 | `LIGHTS` 的日光 / 黄昏 / 夜晚三档 |
| 房间标注文字 | `label('卧室 A', x, z, 高, '副标题')` |

改完存盘、刷新浏览器即可，不需要任何构建步骤。

## 已知取舍

- 这是**按图重建**，尺寸与家具型号取自平面视图的目测比例，并非 skp 的精确坐标
  （skp 的几何只能由 SketchUp 自身导出，本机 Rhino 8 的 `import_SKP` 路径启动失败）。
  若要 1:1 的原始网格，见下。
- 场景为"无顶剖切"表现，没有天花板与灯具的完整造型；夜间模式靠几盏点光源近似。
- 材质为程序化近似，不是 V-Ray 渲染，出正式效果图仍需回 SketchUp + V-Ray。

## 想要 1:1 的原始模型？

`_refs/dsh_export.rb` 是一段可用的 SketchUp 启动脚本（带触发文件保护），
放进 `%APPDATA%\SketchUp\SketchUp 2022\SketchUp\Plugins\` 后启动 SketchUp 打开 skp，
它会自动导出视图图片与 3D 文件（glb / obj / dae）。本机 SketchUp 22.0.316 已实测可用
（导出 glb/obj 时耗时较长，需耐心等）。导出后可换成 `GLTFLoader` 直接载入本场景。
