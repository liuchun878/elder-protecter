点哪里，老奶奶就走到哪里

这是一个可以直接玩的 3D 小演示：用鼠标（或手指）在房间的地板、地毯上点一下，角色会转身、迈步走过去，走路动画和脚步都是实时算出来的。

  • 点地面　指定目的地，地上会出现一个光圈标记
  • 拖动画面　绕着房间转视角；滚轮 拉近拉远
  • 控制台按钮　"去哪里走走" 里可以一键去沙发、茶几、窗边、门口
  • 送药机器人　点"送药过来"，它会开到奶奶面前递上药盒
  • 语音播报 / 大字模式　给视力、听力不便的使用者准备的开关
人物、机器人、房间全部由代码程序化生成（Three.js，无外部模型文件），断网也能跑。
